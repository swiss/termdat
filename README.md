# Termdat

## Introduction

TERMDAT is the terminology database of the Swiss federal administration, developed by the Federal Office of Information Technology, Systems and Telecommunication (FOITT/BIT).
It enables terminology specialists to create, manage, and publish terms and definitions in Switzerland's official languages (German, French, Italian, Romansh) as well as English.
The platform offers simple and extended search, terminology collections and glossaries, role-based workflows, batch editing, duplicate checks, Excel import/export, and RDF export to the LINDAS linked-data service.
The system consists of an Angular frontend (Oblique design system) and a set of .NET APIs (gateway/BFF, private, public, and search APIs) backed by PostgreSQL, RabbitMQ, Keycloak, and Lucene-based full-text search.
